## 5. Technical Performance Optimizations
1. **Zero Client-Side JavaScript Burden:** Using Astro islands only when interactive widgets (e.g., dynamic search, modal inquiry dialogs) require client interactivity.
2. **Modern Image Compression:** All real product photographs must be processed through Astro's image optimization pipeline generating modern WebP and AVIF formats with explicit `width` and `height` attributes to prevent layout shifts (CLS).
3. **Typography Optimization:** Font assets self-hosted with `font-display: swap` and preloaded to prevent FOIT/FOUT.
4. **Automated Sitemap & Robots:** XML sitemap generated dynamically upon static build.
